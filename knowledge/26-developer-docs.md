# Developer documentation

Utvecklardokumentationen finns i `docs/developer/`.

Använd den för frågor om:
- arkitektur och modulgränser,
- schema-/formatutveckling,
- change/migration/versioning,
- tests/fixtures,
- interoperability,
- ZIP/index/prestanda,
- release compatibility.

Maskinläsbara schemas och code/tests är fortsatt normativa där de är mer precisa.

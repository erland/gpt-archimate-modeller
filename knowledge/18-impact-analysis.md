# Impact analysis

Impact analysis bygger på modellerad graph reachability.

Välj direction efter frågan:
- outgoing
- incoming
- both

Direct = depth 1. Indirect = depth 2+.
Path-certainty är strong/moderate/weak och följer svagaste relationship evidence på path.

Resultatet visar modellerad beroendekontext, inte automatiskt verklig kausal påverkan.
Använd paths för spårbarhet.

Seeds kan komma direkt, från change set eller från delta mellan architecture states.
